# Becoming a Terminal Power User: My Journey with Zsh

**My philosophy:** The keyboard is powerful and keeps me in the flow. Every time I reach for the mouse or click through a GUI menu, I'm breaking that flow. Moving your hand from keyboard to mouse? Context switch. Clicking through menus? Context switch. Even the tiny pause to visually locate a button adds up.

With AI assistants and modern command-line tools, you can do so much with just a few keystrokes. Need to search files? `grep` or `rg`. Transform data? Pipe it through commands. Need help? Ask your AI assistant right there in the terminal. We don't need a GUI for everything!

I'm not saying GUIs are evil—I just find myself reaching for the terminal more often than not. Once you get comfortable with a few commands, it's hard to go back to clicking around.

## Setting Up Your .zshrc File

If you're new to terminal customization, the `.zshrc` file is your configuration file. It runs every time you open a new terminal window. This is where you load plugins, create shortcuts, and customize your prompt.

The file lives in your home directory (`~/.zshrc`), and you can edit it with any text editor. After making changes, you can either restart your terminal or run `source ~/.zshrc` to reload the configuration.

Most of the plugins I use are managed through package managers like Homebrew or Oh My Zsh, which makes installation straightforward. Once installed, you simply add a line to your `.zshrc` file to enable each plugin. The setup process is usually well-documented by each tool's maintainers, so even if you're not comfortable editing configuration files, you can follow step-by-step guides.

The key is to start simple—add one tool at a time, test it out, and see if it actually helps. There's no need to configure everything at once. I've been tweaking mine for years, and I'm still finding little improvements.

## z: Smart Directory Navigation

Typing `cd ~/projects/api/src/components/admin/dashboard` gets old fast.

`z` learns your directory habits. It tracks every `cd` and ranks directories using a "frecency" algorithm (frequency + recency). After a day or two, jump to any frequently-used directory with a few keystrokes.

### Usage

```bash
z projects   # Jump to most recent directory
z api        # Partial matches work
z -l projects # List matches before jumping
z -r projects # Jump by rank (most visited)
z -t projects # Jump by time (most recent)
z -c api     # Only search subdirectories
```

### Tips

- Give it a day or two to build data
- Be specific: `z projects api` when multiple matches exist
- Combine: `z api && npm start`

**Not working?** Run `source ~/.zshrc`. **No matches?** Normal—database builds automatically after a few days.
